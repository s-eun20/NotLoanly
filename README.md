## 📌 프로젝트 소개

**‘I'm not Loanly’**는 사용자의 소비 패턴을 분석하고, GPT를 기반으로 **맞춤형 상환 플랜**을 제공하는 비상금 대출 상환 관리 서비스입니다.

### 🔎 주요 기능

- 💸 **비상금 대출 신청 및 잔액 확인**
- 🧠 **GPT 기반 상환 플래너**
  - 소비 패턴 분석 기반 상환 전략 제공
  - 상환 기한/금액 추천
  - 소비를 줄이거나 늘릴 항목 제시
- 🔁 **자동 상환 일정 및 내역 관리**
- 📊 **시각화된 지출 리포트 및 월별 분석**
- 🎯 **사용자 맞춤 목표 설정과 피드백**
- 📩 **리마인더 및 알림 기능**
